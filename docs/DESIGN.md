# KirinukiStudio

UIで実行・操作できる、自動切り抜き動画作成アプリ

## コンセプト

長尺の対談・イベント動画から、文字起こし→話者分離→字幕→切り抜き候補の提案までを
ローカルGPUで一気通貫処理し、プレビューを見ながら短尺動画を量産できるツール。

## 機能

### 文字起こし・字幕
- 字幕生成: 表示位置をUIで制御。最大文字数を参照して自動でサイズ調整。フォント・色・背景を設定可能
- 字幕のトランスクリプト制御: リゾルブ・パンなど主要な表示パターンを数種から選択可能
  - おすすめモードで設定を簡略化
- 代名詞置き換え: 指示語(これ・それ・あれ)を指す内容で補足
  - 積極性3段階(強/中/弱)× 表現形式(かっこ注釈/置換/ニュアンス補完)、有効・無効も切替可能
  - 変更ログを出力し、誤置換を確認可能にする
- フィラー排除: 「なんか」「まあ」「その」「あ、」等の言い淀みを字幕から除去
  - 無効/弱(安全な間投詞のみ)/強(LLM判定で文脈依存語も)。対象語リストは編集可能
- 固有名詞の対話的修正: 表記が確定できない固有名詞(例: 半導体/反動体)をLLM側から質問し、
  回答で全出現箇所を一括修正+用語集登録(以後の文字起こし精度にも反映)
- 字幕採用ジャッジ: 全文字幕/選択字幕モードを切替可能
  - 選択字幕では「聞き取りにくい箇所・固有名詞・理解に必要な文脈」だけを自動字幕化し、1件ずつ手動切替可能
- 話者分離: 話者数・表示名をUIで設定可能。相槌の自動除外も切替可能

### 切り抜き
- アテンション機能: 切り抜きできそうな位置をスコアの根拠付きで提案し、プレビューを見ながら選択・作成
- クリップ単位の再調整: 前後トリム(自然な切れ目にスナップ)・中抜き(ジェットカット)・
  クリップ内指示語の自己完結化・フックテキスト編集
- 目標尺プリセット(Shorts 60秒 / TikTok 30秒 等)と縦型(9:16)自動レイアウト
- タイトル・概要欄・ハッシュタグの自動生成
- 高速書き出し: テンプレート適用で一つの動画から複数の切り抜きを一括生成
- 簡易的な動画編集機能
  - オープンソースの動画編集アプリのUIを参考に。最低限で良い

### 実行環境
- ローカル動作 / クラウドAPI動作をモデル単位で選択可能
- GPU処理対応(まずCUDA。ROCmは将来対応 → 制約の節を参照)

## アーキテクチャ

詳細設計: [BACKEND_DESIGN.md](BACKEND_DESIGN.md)(ASRはfaster-whisper large-v3既定・精度優先/単語TS必須)/ [FRONTEND_DESIGN.md](FRONTEND_DESIGN.md)(React + TypeScript)
実装計画: [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)(マイルストーン別・受け入れ基準付き)

```
┌─ フロントエンド: React + TypeScript(ローカルWebアプリ)
│   ・動画プレビュー: HTML5 <video> + CSSオーバーレイ字幕
│   ・波形/タイムライン: wavesurfer.js 等の既製ライブラリ
│   ・進捗表示: WebSocket/SSEでバックエンドから受信
├─ バックエンド: Python + FastAPI
│   ・文字起こしジョブ: faster-whisper(large-v3, float16)
│   ・話者分離: pyannote.audio 3.x + ピッチによる話者名自動割り当て
│   ・代名詞置換: ローカルLLM(Ollama)/ クラウドAPIを切替可能
│   ・書き出し: ffmpeg
└─ 起動形態: uv run で起動 → ブラウザで localhost を開く
    (デスクトップアプリ化が必要になったら後からTauriで包む)
```

- MVPは「設定+実行+結果閲覧」のみGradioで先行実装し、
  タイムライン・切り抜き調整UIの段階でReactに移行する二段構えも可

## 制約・技術メモ

- faster-whisper(CTranslate2)は実質CUDA専用。ROCm対応するなら whisper.cpp か
  PyTorch版Whisperへの切替経路が必要。初期リリースはCUDA限定が現実的
- Blackwell世代GPU(RTX 50 / RTX PRO 6000)ではint8がクラッシュするため float16 固定
- pyannote.audio はHuggingFaceトークン必須(`hf_token.txt`)。依存バージョンは
  pyproject.toml で固定済み(pyannote 3.x / torch 2.8 / huggingface_hub 0.x)
- 代名詞置換の3段階チューニングは、プロンプトの確信度閾値+置換文字列長の
  上限のパラメータ化で実現する想定
